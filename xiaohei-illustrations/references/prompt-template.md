# 이미지 생성 프롬프트

한 장씩 사용한다. 중괄호 부분을 실제 본문에 맞게 바꾸며, 허용 문구를 먼저 확정한다.

```text
한국어 글의 본문에 넣을 독립된 16:9 가로형 그림 한 장을 생성한다.

시각 스타일:
순백색 배경. 가늘고 조금 흔들리는 검은 손그림 선. 넓은 여백.
빨강, 주황, 파랑은 필요한 부분에만 절제해 사용한다.
그림자, 그라데이션, 종이 질감, 복잡한 배경, 정교한 벡터 느낌,
발표 슬라이드, 상업용 포스터, 어린이 만화와 실제 앱 화면은 제외한다.

캐릭터:
샤오헤이는 작은 검은 몸, 흰 점 눈, 가느다란 팔다리,
담담하고 진지한 표정을 가진 캐릭터다.
샤오헤이가 핵심 행동을 직접 수행해야 하며 옆에서 구경만 하지 않는다.

캐릭터 참조 이미지:
`assets/reference/xiaohei-character-reference.png`를 Image 1의 캐릭터 외형 참조로 첨부한다.
참조 이미지의 검은 몸, 흰 점 눈, 가느다란 팔다리, 단순한 실루엣과 담담한 인상만 유지한다.
참조 이미지의 자세, 배경, 소품, 배치와 구도는 복제하지 않고 현재 장면을 새로 구성한다.

주제: {그림의 주제}
핵심 생각: {독자가 이해해야 할 한 가지 생각}
구성 유형: {작업 흐름 / 전후 비교 / 개념 비유 등. 그림에는 쓰지 않음}
장면: {캐릭터의 위치와 행동, 주요 물건, 움직임을 구체적으로 설명}
주요 요소: {필요한 물건 1~2개와 보조 요소}

그림에 넣을 정확한 한글 문구:
{문구 1}
{문구 2}
{문구 3}
{필요한 경우에만 문구 추가}

위 문구만 정확하게 쓴다. 새 문구, 번역, 숫자, 제목을 임의 추가하지 않는다.
한글은 짧고 충분히 크게 쓰고 글자가 겹치거나 잘리지 않게 한다.
검정은 선과 캐릭터, 주황은 주요 움직임, 빨강은 문제와 강조,
파랑은 보조 설명과 피드백에만 사용한다.

한 장에 하나의 핵심 생각. 주요 장면은 화면의 약 40~60%.
최소 35%는 빈 흰 공간. 한글 주석은 보통 3~5개, 최대 8개.
개인 이름, 서명, 로고, 연락처, 홍보 문구, QR 코드를 넣지 않는다.
특정 예제를 재현하라는 요청이 없으면 새로운 물건과 행동으로 구성한다. 참조 이미지는 캐릭터 외형에만 사용한다.
```

## 제목 또는 문구 제거

```text
제공된 이미지를 편집한다. {위치}의 "{삭제할 문구}"와 그 밑줄만 제거한다.
해당 영역을 주변과 같은 순백색으로 복원한다.
캐릭터, 다른 글자, 물건, 선, 색, 구도, 비율과 화질은 유지한다.
새 문구나 물건은 추가하지 않는다.
```

## 한글 오탈자 수정

```text
제공된 이미지에서 {위치}의 "{잘못된 문구}"만 "{정확한 문구}"로 수정한다.
뜻, 글자 크기, 색, 손글씨 느낌과 여백을 유지한다.
다른 글자와 그림은 바꾸지 않는다. 한글을 다른 언어로 대체하지 않는다.
```

## 캐릭터 행동 강화

```text
핵심 생각과 단순한 구도는 유지한다.
샤오헤이가 {핵심 행동}을 직접 수행하도록 장면을 다시 구성한다.
캐릭터를 제거하면 행동이 성립하지 않아야 한다.
순백색 배경, 넓은 여백, 짧고 정확한 한글 주석을 유지한다.
```
