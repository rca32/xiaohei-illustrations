# 생성 결과 검수

## 필수 확인

- [ ] 16:9 가로형이며 깨끗한 순백색 배경이다.
- [ ] 샤오헤이가 핵심 행동을 직접 수행한다.
- [ ] 샤오헤이의 검은 몸, 흰 점 눈, 가느다란 팔다리와 담담한 인상이 참조 이미지와 일치한다.
- [ ] 현재 글의 의미를 표현하며 요청하지 않은 예제 복제가 아니다.
- [ ] 한 장에 핵심 생각이 하나뿐이고 물건과 화살표가 과하지 않다.
- [ ] 주요 장면이 화면의 약 60%를 넘지 않으며 넓은 여백이 있다.
- [ ] 주석은 짧은 한국어이고 사용자가 지정한 문구와 일치한다.
- [ ] 철자, 띄어쓰기, 조사, 글자 잘림, 겹침을 직접 확인했다.
- [ ] 임의의 제목, 서명, 연락처, 홍보 문구와 QR 코드가 없다.
- [ ] 주황은 움직임, 빨강은 강조, 파랑은 보조 설명에 제한했다.
- [ ] 실제 생성 파일을 열어 확인했으며 예시나 계획을 완성본으로 소개하지 않는다.

## 수정이 필요한 신호

발표 슬라이드, 정식 순서도, 수업 자료처럼 보이거나 귀여운 마스코트가 장면을 장악하면 다시 구성한다. 베이지색, 종이 질감, 그림자, 그라데이션, 앱 화면, 빽빽한 노드도 기본 스타일과 맞지 않는다.

한글이 심하게 틀리거나 요청하지 않은 언어가 섞이면 수정한다. 글자가 읽히지 않는 이미지는 완성본으로 전달하지 않는다.

## 수정 방법

평범하면 캐릭터의 행동과 물리적 비유를 강화한다. 복잡하면 물건과 연결을 줄인다. 너무 귀여우면 무표정하고 진지한 인상을 강조한다. 도표 같으면 격자, 제목, 테두리와 화살표를 덜어낸다.

오탈자가 적으면 해당 글자만 편집한다. 문제가 많으면 주석의 수와 길이를 줄여 재생성한다. 이전 예제와 너무 닮았으면 핵심 생각은 유지하되 주요 물건과 행동을 바꾼다.

## 전달 기준

독자가 먼저 조금 엉뚱하다고 느낀 뒤 핵심 생각을 바로 이해할 수 있어야 한다. 생성 장수와 실제 파일 경로를 확인하고, 미완성이나 검수하지 못한 부분은 숨기지 않는다.
