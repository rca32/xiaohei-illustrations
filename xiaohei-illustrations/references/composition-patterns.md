# 구성과 새로운 비유 만들기

## 구성 유형

한 장에는 아래 유형 중 하나를 중심으로 사용한다. 유형 이름을 그림 안에 제목으로 쓰지 않는다.

| 유형 | 어울리는 내용 | 구성의 핵심 |
| --- | --- | --- |
| 작업 흐름 | 입력, 처리, 출력 | 주요 움직임 하나와 행동하는 캐릭터 |
| 시스템 일부 | 수집, 필터, 저장, 도구 연결 | 핵심 요소 3~5개만 선택 |
| 전후 비교 | 혼란과 정리, 수동과 자동 | 달라진 상태 하나를 대비 |
| 캐릭터 상태 | 과부하, 막힘, 안정 | 짧은 상태 2~4개 |
| 개념 비유 | 검증, 신뢰, 축적 | 기억에 남는 물건과 행동 하나 |
| 방법의 층위 | 단계, 역량, 기반 | 쌓거나 지지하는 관계 |
| 경로 | 학습, 실행, 인계 | 적은 지점과 하나의 경로 |
| 짧은 연속 장면 | 시행착오, 변화 | 행동이 하나씩 담긴 장면 2~4개 |

## 비유를 만드는 순서

1. 추상 개념을 걸러내기, 막히기, 새기, 무거워지기, 접기, 잇기, 쌓기 같은 물리적 행동으로 바꾼다.
2. 복잡한 시스템을 체, 상자, 서랍, 문, 저울, 사다리, 우체통, 손잡이, 물레 같은 단순한 물건 1~2개로 바꾼다.
3. 샤오헤이가 직접 당기고, 고치고, 밀고, 받거나 조작하도록 만든다.

엉뚱함 자체보다 행동과 원문의 의미가 연결되는지가 중요하다. 정보가 새는 글에 구멍 난 통을 사용할 수 있지만, 근거 없는 인과관계나 원문에 없는 수치를 덧붙이지 않는다.

## 예제를 복제하지 않기

`assets/examples/`는 한국어 표기와 장면 관계를 확인하는 구성 예제다. 기본 생성 경로에서 매번 열거나 모델에 참조 이미지로 제공하지 않는다.

사용자가 해당 예제를 지정한 경우를 제외하면 체로 정보 거르기, 작은 시험 장치, 원본을 여러 형식으로 가공하기, 맥락 상자 전달하기 등 동봉 예제의 구도를 그대로 사용하지 않는다. 같은 주제라도 물건과 행동을 새로 고른다.

예를 들어 맥락 인계는 상자 대신 다음 사람이 이어 쓸 수 있도록 매듭을 정리하는 행동으로 표현할 수 있다. 콘텐츠 재사용은 가공 장치 대신 접는 방식에 따라 다른 물건이 되는 종이로 표현할 수 있다.
