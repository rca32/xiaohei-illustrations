# 한국어판 안내

이 저장소는 기존 본문 일러스트 스킬을 한국어 글과 한글 이미지 표기에 맞게 수정한 버전입니다. 스킬 이름과 설치 폴더는 `xiaohei-illustrations`로 통일했습니다.

문서, 프롬프트, 에이전트 설명, 구성 예제를 한국어로 변경했으며 개인 소개, 연락처, 홍보 링크와 QR 자산은 배포 파일에서 제거했습니다. 과거 중국어 PNG 예제는 현재 배포에 포함하지 않습니다.

설치 폴더에 동봉된 `assets/examples/`의 PNG 8개는 이미지 생성 도구로 새로 만든 장면 구성 및 한글 표기 예시입니다. 순백색 배경, 16:9 비율, 샤오헤이의 핵심 행동과 한글 표기를 직접 검수했습니다.

`assets/reference/xiaohei-character-reference.png`는 이미지 생성 도구로 만든 샤오헤이 캐릭터 참조 이미지입니다. 이후 본문 그림 생성에서 캐릭터 외형을 맞추는 입력 이미지로 사용하며, 참조 이미지의 장면과 소품을 그대로 복제하지 않습니다.

원본 소프트웨어의 저작권 고지와 이용 조건은 같은 디렉터리의 `LICENSE`에 보존합니다. 저장소 루트와 설치용 스킬 폴더 모두에 라이선스를 동봉합니다. 이 수정은 새로운 권리 소유나 원저작자의 보증을 주장하지 않습니다.
