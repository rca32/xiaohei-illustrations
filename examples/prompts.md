## 한국어 주제 8개

다음은 단일 이미지 요청 예시입니다. 동봉된 PNG는 이미지 생성 도구로 만든 결과이며, 새로운 글을 작업할 때는 그 글에 맞는 비유를 다시 만드세요.

### 1. 정보 과부하

```text
$xiaohei-illustrations
정보를 많이 모으기보다 필요한 것을 선별하는 일이 중요하다는 생각을 한 장으로 그려 줘.
샤오헤이가 커다란 체를 움직여 종이 더미에서 필요한 쪽지만 남기는 장면이야.
그림 속 문구는 "모으기", "선별", "핵심만"만 사용해 줘.
```

### 2. 작은 검증

```text
$xiaohei-illustrations
큰 시스템을 만들기 전에 작은 실험으로 가설을 확인한다는 생각을 한 장으로 그려 줘.
샤오헤이가 작은 시험 장치의 손잡이를 돌리며 종이 모형을 확인하게 해.
그림 속 문구는 "가설", "작게 실험", "확인"만 사용해 줘.
```

### 3. 콘텐츠 재사용

```text
$xiaohei-illustrations
원본 자료 하나를 여러 형식으로 가공한다는 생각을 한 장으로 그려 줘.
샤오헤이가 손으로 돌리는 압착 장치에 원본 종이를 넣어 서로 다른 결과물을 만들게 해.
그림 속 문구는 "원본", "요약", "그림", "음성"만 사용해 줘.
```

### 4. 맥락 인계

```text
$xiaohei-illustrations
파일만 넘기지 말고 목표와 결정과 다음 행동을 함께 전달해야 한다는 생각을 한 장으로 그려 줘.
두 샤오헤이가 작은 틈 너머로 손잡이 달린 맥락 상자를 주고받게 해.
그림 속 문구는 "목표", "결정", "다음 단계"만 사용해 줘.
```

### 5. 근거로 판단하기

```text
$xiaohei-illustrations
주장의 크기보다 근거의 무게를 확인해야 한다는 생각을 한 장으로 그려 줘.
샤오헤이가 저울 한쪽의 빈 말풍선과 다른 쪽의 근거 조각을 직접 비교하게 해.
그림 속 문구는 "주장", "근거", "검증"만 사용해 줘.
```

### 6. 반복 개선

```text
$xiaohei-illustrations
한 번 실행하고 끝내지 말고 결과를 관찰해 다음 실행을 개선한다는 생각을 한 장으로 그려 줘.
샤오헤이가 손 펌프로 작은 싹에 물을 보내고 돌아온 상태 표시를 보고 손잡이를 조절하게 해.
그림 속 문구는 "실행", "관찰", "개선"만 사용해 줘.
```

### 7. 우선순위

```text
$xiaohei-illustrations
모든 일을 동시에 시작하기보다 지금 중요한 일을 하나씩 통과시킨다는 생각을 한 장으로 그려 줘.
샤오헤이가 좁은 문으로 작업 상자를 하나만 밀어 넣고 나머지는 밖에 두게 해.
그림 속 문구는 "지금", "나중", "한 번에 하나"만 사용해 줘.
```

### 8. 기록의 축적

```text
$xiaohei-illustrations
짧은 기록을 연결하면 다음 작업에서 다시 쓸 수 있는 지식이 된다는 생각을 한 장으로 그려 줘.
샤오헤이가 작은 쪽지들을 실로 이어 커다란 조각 천처럼 만들게 해.
그림 속 문구는 "기록", "연결", "재사용"만 사용해 줘.
```
